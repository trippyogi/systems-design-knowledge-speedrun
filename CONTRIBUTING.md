# Contributing

Contributions should be small and useful.

Good contributions:

- A one-page concept explainer
- A design kata
- A solved kata with tradeoffs
- A Mermaid diagram
- An ADR example
- A failure-mode table
- A rubric improvement

Contribution rules:

1. Keep explanations practical.
2. Include the problem a concept solves.
3. Include at least one tradeoff.
4. Prefer vendor-neutral ideas.
5. Cite authoritative resources when adding factual claims.
6. Avoid dumping huge notes.
