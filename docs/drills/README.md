# Design Katas

Each kata should take 30 to 60 minutes.

For each kata, create:

1. Requirements
2. Estimates
3. API sketch
4. Data model
5. Architecture diagram
6. Scaling plan
7. Failure mode table
8. Observability plan
9. ADR for the biggest tradeoff
10. Rubric score

## Katas by difficulty

### Beginner

- URL shortener
- Pastebin
- Rate limiter
- Notification service

### Intermediate

- News feed
- Chat system
- File storage
- Search autocomplete
- Webhook delivery platform

### Advanced

- Ticket booking / inventory reservation
- Metrics ingestion pipeline
- Multi-tenant SaaS API platform
- Collaborative document editing
- Global payment ledger discussion only, not implementation
