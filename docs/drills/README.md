# Design Katas

Each kata is a rep. Do not only read the prompt.

## Kata loop

1. Design from memory first.
2. Run the AI design-review prompt.
3. Diff against a worked solution when available.
4. Rewrite the weakest section.
5. Teach it back in 10 lines or 5 minutes.

## What every kata should produce

1. Requirements and non-goals
2. Estimates
3. API sketch
4. Data model and access patterns
5. Architecture diagram
6. Scaling plan
7. Failure mode table
8. Observability plan
9. ADR for the biggest tradeoff
10. AI-review notes
11. Worked-solution diff when available
12. Teach-back
