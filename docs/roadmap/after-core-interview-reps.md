# 30-Day Interview + Production Sprint

Assumption: 5 to 8 hours per week.

## Week 1 — Core building blocks

Focus:

- Requirements
- Sizing
- APIs
- Data models
- Caching
- Load balancing

Katas:

- URL shortener
- Pastebin
- Rate limiter

## Week 2 — Data-intensive systems

Focus:

- Indexes
- Replication
- Partitioning
- Consistency
- Search
- Analytics vs serving paths

Katas:

- News feed
- Search autocomplete
- Metrics ingestion

## Week 3 — Async and event-driven systems

Focus:

- Queues
- Streams
- Workers
- Idempotency
- Backpressure
- Dead-letter queues
- Eventual consistency

Katas:

- Notification service
- Video processing pipeline
- Webhook delivery platform

## Week 4 — Production readiness

Focus:

- SLOs
- Observability
- Disaster recovery
- Security
- Abuse prevention
- Cost
- Deployment strategy

Katas:

- Chat system
- Ticket booking or inventory reservation
- Multi-tenant SaaS API

## Weekly deliverables

Each week produce:

1. Two one-page design docs.
2. One ADR.
3. One failure mode table.
4. One 5-minute teach-back recording or written script.
5. One rubric scorecard.

## Interview-ready bar

You are ready when you can handle a prompt in 45 minutes and produce:

- Requirements and assumptions
- Back-of-envelope estimates
- API sketch
- Data model
- Baseline design
- Scaling plan
- Failure modes
- Tradeoffs
- Operational plan
