# Visuals

This repo uses diagrams to compress knowledge.

## Recommended visual stack

- **C4 diagrams** for architecture zoom levels.
- **Sequence diagrams** for request flows and async workflows.
- **Skill trees** for learning paths.
- **Failure maps** for production readiness.
- **ADR timelines** for decisions over time.

## Files

- `skill-tree.mmd` — Mermaid skill tree source.
- `design-flow.mmd` — Mermaid system design conversation loop.
- `skill-tree.svg` — Static SVG version of the skill tree.

GitHub renders Mermaid in Markdown, so most diagrams can live directly in docs.
